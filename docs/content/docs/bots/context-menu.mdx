**Context Menu Commands** are quick interactions triggered when users right-click a message or a user. They provide a streamlined way to offer contextual actions within Discord.

## Creating Context Commands

To create a context menu command, add a file to the appropriate subdirectory within your project's `src/context` folder. The file name will be used as the command name (spaces and capitalization are allowed).

- **Message Commands**: Place files in `src/context/message`.
- **User Commands**: Place files in `src/context/user`.

## Examples
### Message Command

When a message context menu command is invoked, your function will receive a `MessageContextMenuCommandInteraction{:ts}` object and the target `Message{:ts}`.

<Tabs groupId="examples-script" items={['Javascript', 'Typescript']} persist>
  <Tab value="Javascript">
    ```javascript title="src/context/message/Translate.js"
    import { translateMessage } from '../services/translator.js'

    export default async (interaction, message) => {
      const translatedContent = await translateMessage(message.content)
      interaction.reply(`Translation: ${translatedContent}`)
    }
    ```
  </Tab>
  <Tab value="Typescript">
    ```typescript title="src/context/message/Translate.ts"
    import { translateMessage } from '../services/translator.js'
    import type { MessageContextMenuCommandInteraction, Message } from 'discord.js'
    import type { CommandResult } from 'robo.js'

    export default async (interaction: MessageContextMenuCommandInteraction, message: Message): Promise<CommandResult> => {
      const translatedContent = await translateMessage(message.content)
      return `Translation: ${translatedContent}`
    }
    ```
  </Tab>
</Tabs>

### User Command

For user context menu commands, you'll receive a `UserContextMenuCommandInteraction{:ts}` object and the target `User{:ts}`.

<Tabs groupId="examples-script" items={['Javascript', 'Typescript']} persist>
  <Tab value="Javascript">
    ```javascript title="src/context/user/Kick.js"
    export default async (interaction, user) => {
      const member = await interaction.guild.members.fetch(user.id)
      if (member) {
        await member.kick('Kicked via context menu command.')
        interaction.reply(`Kicked ${user.username}.`)
      } else {
        interaction.reply({ content: 'Could not find member to kick.', ephemeral: true })
      }
    }
    ```
  </Tab>
  <Tab value="Typescript">
    ```typescript title="src/context/user/Kick.ts"
    import type { UserContextMenuCommandInteraction, User } from 'discord.js'
    import type { CommandResult } from 'robo.js'

    export default async (interaction: UserContextMenuCommandInteraction, user: User): Promise<CommandResult> => {
      const member = await interaction.guild.members.fetch(user.id)
      if (member) {
        await member.kick('Kicked via context menu command.')
        return `Kicked ${user.username}.`
      } else {
        return { content: 'Could not find member to kick.', ephemeral: true }
      }
    }
    ```
  </Tab>
</Tabs>

## Customizing Context Menu Commands

You can customize context menu commands by exporting a `config{:ts}` object from your command file. This allows you to set properties such as default member permissions and whether the command can be used in DMs.

<Tabs groupId="examples-script" items={['Javascript', 'Typescript']} persist>
  <Tab value="Javascript">
    ```javascript title="src/context/message/Translate.js"
    import { createCommandConfig } from 'robo.js'
    import { translateMessage } from '../services/translator.js'

    export const config = createCommandConfig({
      defaultMemberPermissions: 'ManageMessages', // Only users who can manage messages can use this
      dmPermission: false // Cannot be used in DMs
    })

    export default async (interaction, message) => {
      const translatedContent = await translateMessage(message.content)
      interaction.reply(`Translation: ${translatedContent}`)
    }
    ```
  </Tab>
  <Tab value="Typescript">
    ```typescript title="src/context/message/Translate.ts"
    import { createCommandConfig } from 'robo.js'
    import { translateMessage } from '../services/translator.js'
    import type { MessageContextMenuCommandInteraction, Message } from 'discord.js'
    import type { CommandConfig, CommandResult } from 'robo.js'

    export const config: CommandConfig = createCommandConfig({
      defaultMemberPermissions: 'ManageMessages', // Only users who can manage messages can use this
      dmPermission: false // Cannot be used in DMs
    })

    export default async (interaction: MessageContextMenuCommandInteraction, message: Message): Promise<CommandResult> => {
      const translatedContent = await translateMessage(message.content)
      return `Translation: ${translatedContent}`
    }
    ```
  </Tab>
</Tabs>

Context menu commands leverage the same underlying system as slash commands, including Sage for streamlined interaction replies. This ensures a consistent and powerful development experience.
