**Robo.js** makes building bots with **[Discord.js](https://discord.js.org)** as easy as placing files in the right place.

Create a **[Slash Command](./commands.mdx)** by making a file in `/src/commands`; the file name becomes the command. **[Context Commands](./context-menu.mdx)** and **[Events](./events.mdx)**? Just as easy! This is more than just a command handler - it's a full-fledged **[Framework](../framework/index.mdx)** and **[Ecosystem](/directory)**.

**Got an existing bot?** See the **[Migration Guide](./migrate.mdx)**.

<Callout type="info" title="Not a replacement">
Robo.js does not replace Discord.js! Instead, it simplifies development by managing your project. You still have all of **Discord.js**!
</Callout>

## Quick Start

Ready to start your adventure? Try **[Create Robo](../framework/cli/create-robo.mdx)** in your terminal:

```package-install
npx create-robo <projectName>
```

This will help spawn a new **Robo.js** project as a **Discord Bot**. We call these **Robos**.

## Plugin Power Ups

**[Robo Plugins](../framework/plugins/overview.mdx)** are special. They let you add features to your **Robo** with one command.

```package-install
npx robo add @robojs/ai @robojs/moderation
```

Plugins integrate seamlessly thanks to the **[Robo File Structure](../framework/core/files.mdx)**. What's more, anyone can **[create a plugin](../framework/plugins/create.mdx)**.

## Frequently Asked Questions

<Accordions type="single">
  <Accordion title="Can I use my existing code?">

Yes! **Robo.js** is built on top of **Discord.js** and is fully compatible with existing bots. Check out the **[Migration Guide](./migrate.mdx)** for more info.

  </Accordion>
  <Accordion title="Can I use any database? Am I forced to use Flashcore?">

**Robo.js** is database agnostic. You can use any database you like, including Flashcore, MongoDB, or even a simple JSON file.

We recommend **Flashcore** for its simplicity, but more mature projects may benefit from a more robust database like MySQL or PostgreSQL. We have **[Templates](/templates?filter=discord-bots)** for those!

  </Accordion>
  <Accordion title="Do I have to use TypeScript?">

Nope! **Robo.js** supports both JavaScript and TypeScript. You can use either or both in the same project.

When creating a new project, uncheck the TypeScript option if you want to use JavaScript. You can always add it later.

  </Accordion>
  <Accordion title="How do I register my commands?">

**You don't!**

**Robo.js** automatically registers your commands when you create them in the `/src/commands` directory. It internally uses a manifest to keep track of changes and only register when necessary.

  </Accordion>
  <Accordion title="Should I still create my own client?">

Nope, **Robo.js** handles the client for you. Configure it in `/config/robo.mjs` and import it via `import { client } from 'robo.js'`. Check the **[Configuration Guide](../framework/core/config.mdx)** for more info.

  </Accordion>
  <Accordion title="What is ESM? Why can't I use `require`?">

ESM (ECMAScript Modules) is the new standard for JavaScript modules. **Robo.js** exclusively uses ESM.

`import` is more powerful than `require` and allows for better tree-shaking and static analysis.

  </Accordion>
</Accordions>
