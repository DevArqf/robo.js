Discord bots built with Robo.js follow a simple yet powerful file structure that automatically maps to Discord's features. This structure makes it intuitive to organize your bot's commands, events, and context menus.

## Core Directories

Robo.js bots typically contain these directories within your project's `/src` folder:

<Files>
  <Folder name="src" defaultOpen disabled>
    <Folder name="commands" disabled />
    <Folder name="context" disabled />
    <Folder name="events" disabled />
  </Folder>
</Files>

- **`/commands`**: Contains slash commands. Can be nested for subcommands or subcommand groups.
- **`/context`**: Holds context menu commands, organized by type (`user` or `message`).
- **`/events`**: Contains Discord event handlers, which can be grouped by event type.

## Examples

### Basic

Here's a minimal bot structure with a single command and event:

<Files>
  <Folder name="src" defaultOpen disabled>
    <Folder name="commands" defaultOpen>
      <File name="ping.js" />
    </Folder>
    <Folder name="events" defaultOpen>
      <File name="messageCreate.js" />
    </Folder>
  </Folder>
</Files>

This structure creates:
- A `/ping` slash command
- A `messageCreate` event handler

### Advanced

For more complex bots, you can nest files to create subcommands and group related functionality:

<Files>
  <Folder name="src" defaultOpen disabled>
    <Folder name="commands" defaultOpen>
      <File name="ping.js" />
      <Folder name="ban" defaultOpen>
        <File name="user.js" />
      </Folder>
      <Folder name="settings" defaultOpen>
        <Folder name="update" defaultOpen>
          <File name="something.js" />
        </Folder>
      </Folder>
    </Folder>
    <Folder name="context" defaultOpen>
      <Folder name="user" defaultOpen>
        <File name="Audit.js" />
      </Folder>
      <Folder name="message" defaultOpen>
        <File name="Report.js" />
      </Folder>
    </Folder>
    <Folder name="events" defaultOpen>
      <File name="ready.js" />
      <Folder name="messageCreate" defaultOpen>
        <File name="dm.js" />
        <File name="hello.js" />
      </Folder>
    </Folder>
  </Folder>
</Files>

This structure creates:
- `/ping` command
- `/ban user` subcommand
- `/settings update something` subcommand group
- `Audit` user context command
- `Report` message context command
- `ready` event
- `dm` and `hello` grouped `messageCreate` events
