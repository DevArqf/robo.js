**Robo.js** is a powerful framework for building epic **Discord** experiences.

It lets you **[reduce boilerplate](./framework/core/files.mdx)**, **[add features instantly](./framework/plugins/overview.mdx)**, **[follow best practices](./bots/sage.mdx)**, **[deploy with ease](./framework/hosting/overview.mdx)**, **[persist data](./framework/core/flashcore.mdx)**, **[debug inline](./bots/debug.mdx)**, **[share features](./framework/plugins/create.mdx)**, **[manage state](./framework/core/state.mdx)**, **[stay organized](./framework/core/modules.mdx)**, **[join an ecosystem](./framework/plugins/overview.mdx)**, and **[so much more](./framework/core/overview.mdx)**. All for **[less than 700kB](https://packagephobia.com/result?p=robo.js)**.

Best of all, **[it works with your existing code](./bots/migrate.mdx)**. You may even find it **[fun](./bots/sage.mdx)**!

## Quick Start

Ready to start your adventure? Try **[Create Robo](./framework/cli/create-robo.mdx)** in your terminal:

```package-install
npx create-robo <projectName>
```

This will spawn a new **Robo.js** project ready to use. We call these **Robos**.

## Plugin Power Ups

**[Robo Plugins](./framework/plugins/overview.mdx)** are special. They let you add features to your **Robo** with one command.

```package-install
npx robo add @robojs/ai @robojs/server
```

Plugins integrate seamlessly thanks to the **[Robo File Structure](./framework/core/files.mdx)**. What's more, anyone can **[create a plugin](./framework/plugins/create.mdx)**.
