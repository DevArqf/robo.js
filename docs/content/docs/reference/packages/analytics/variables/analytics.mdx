# Variable: Analytics

```ts
const Analytics: Readonly<object>;
```

A global interface for tracking analytics events and page views in your Robo.js application.

## Type Declaration

### event()

```ts
event: (name, options?) => void | Promise<void>;
```

Tracks an event with the configured analytics engines.

#### Parameters

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `name` | `string` | The name of the event to track |
| `options` | `EventOptions` | Optional configuration for the event |

#### Returns

`void | Promise<void>`

### isReady()

```ts
isReady: () => boolean;
```

Checks if analytics tracking is ready to use.

#### Returns

`boolean` - True if analytics is initialized and ready to use

### view()

```ts
view: (page, options?) => void | Promise<void>;
```

Tracks a page view with the configured analytics engines.

#### Parameters

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `page` | `string` | The page path to track |
| `options` | `ViewOptions` | Optional configuration for the page view |

#### Returns

`void | Promise<void>`

## Example

```ts
import { Analytics } from '@robojs/analytics'

// Check if analytics is ready
if (Analytics.isReady()) {
  // Track a page view
  Analytics.view('/dashboard')
  
  // Track an event with properties
  Analytics.event('button_click', {
    properties: {
      button_id: 'submit-form',
      page: 'checkout'
    }
  })
  
  // Track a conversion event
  Analytics.event('purchase_complete', {
    properties: {
      value: 99.99,
      currency: 'USD',
      items: 3
    }
  })
}
```

## EventOptions Type

| Property | Type | Description |
| -------- | ---- | ----------- |
| `properties` | `Record<string, any>` | Custom properties to track with the event |
| `callback` | `() => void` | Optional callback to execute when tracking is complete |

## ViewOptions Type

| Property | Type | Description |
| -------- | ---- | ----------- |
| `title` | `string` | Page title |
| `properties` | `Record<string, any>` | Custom properties to track with the page view |
| `callback` | `() => void` | Optional callback to execute when tracking is complete |

## Notes

- The Analytics variable is a singleton that works with all configured analytics engines
- Events and page views are sent to all configured engines automatically
- Use proper event naming conventions for consistency (e.g., snake_case for event names)
- For more advanced use cases, you can use the specific analytics engine classes directly
