# Function: useSyncState()

```ts
function useSyncState<T>(initialState, key): readonly [T, (newState) => void]
```

A React hook that provides synchronized state across components and instances, similar to React's `useState` but with synchronization capabilities.

## Type Parameters

| Type Parameter | Description |
| -------------- | ----------- |
| `T` | The type of the state value |

## Parameters

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `initialState` | `T` | The initial state value |
| `key` | `(null \| string)[]` | Array of keys that uniquely identify this state |

## Returns

`readonly [T, (newState) => void]` - A tuple containing the current state value and a function to update it

## Example

```tsx
import { useSyncState } from '@robojs/sync'

function Counter() {
  // Create a synchronized counter state
  const [count, setCount] = useSyncState(0, ['counter'])
  
  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>
        Increment
      </button>
    </div>
  )
}

// In another component or instance
function CounterDisplay() {
  // This will sync with the same counter state
  const [count] = useSyncState(0, ['counter'])
  
  return (
    <div>
      <p>Counter value: {count}</p>
      <p>This display will update when any component changes the counter!</p>
    </div>
  )
}
```

## Notes

- The state is synchronized across all components that use the same key
- Changes to the state in one component will reflect in all others
- The key array must be consistent across all instances to ensure proper synchronization
- Using `null` in key positions allows for dynamic key hierarchies
- The API mimics React's `useState` for familiarity, but with added synchronization
- This hook requires the parent component tree to include the `SyncContextProvider`
