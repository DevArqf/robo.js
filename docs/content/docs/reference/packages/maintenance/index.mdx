# @robojs/maintenance

Maintenance mode utilities for Discord bots.

<Cards>
  <Card href="/docs/plugins/maintenance" title="Plugin Guide" description="Full documentation and usage examples." />
</Cards>

## Main Exports

### Maintenance

Main maintenance mode controls.

```typescript
import { Maintenance } from '@robojs/maintenance'

// Check if in maintenance mode
const isActive = Maintenance.isActive()

// Enable maintenance mode
await Maintenance.enable('Updating database...')

// Disable maintenance mode
await Maintenance.disable()
```

## Included Commands

- `/maintenance on` - Enable maintenance mode
- `/maintenance off` - Disable maintenance mode
- `/maintenance status` - Check current status

## Configuration

```javascript title="config/plugins/robojs/maintenance.mjs"
export default {
  allowedUsers: ['user-id-1', 'user-id-2'],
  message: 'Bot is currently under maintenance. Please try again later.'
}
```
