# @robojs/dev

Development utilities for Robo.js projects.

  <Card href="/docs/plugins/dev" title="Plugin Guide" description="Full documentation and usage examples." />

## Main Exports

### DevTools

Development utilities for debugging and inspection.

```typescript
import { DevTools } from '@robojs/dev'

// Get Robo state
const state = DevTools.getState()

// Get registered commands
const commands = DevTools.getCommands()

// Get active events
const events = DevTools.getEvents()
```

## Included Commands

The plugin adds `/dev` subcommands for quick access to development information:

- `/dev state` - View current Robo state
- `/dev logs` - View recent logs
- `/dev system` - View system information
- `/dev commands` - List registered commands

## Configuration

Enable or disable specific dev commands:

```javascript title="config/plugins/robojs/dev.mjs"
export default {
  commands: {
    state: true,
    logs: true,
    system: true
  }
}
```
