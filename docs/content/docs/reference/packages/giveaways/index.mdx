# @robojs/giveaways

Create and manage Discord giveaways with automated winner selection.

<Cards>
  <Card href="/docs/plugins/giveaways" title="Plugin Guide" description="Full documentation and usage examples." />
</Cards>

## Main Exports

### Giveaway

Main giveaway management class.

```typescript
import { Giveaway } from '@robojs/giveaways'

// Create a giveaway
const giveaway = await Giveaway.create({
  channel: channelId,
  prize: 'Discord Nitro',
  duration: 86400000, // 24 hours
  winners: 1
})

// End a giveaway
const winners = await Giveaway.end(giveawayId)

// Reroll winners
const newWinners = await Giveaway.reroll(giveawayId)
```

### GiveawayManager

Manage all active giveaways.

```typescript
import { GiveawayManager } from '@robojs/giveaways'

// Get active giveaways
const active = await GiveawayManager.getActive(guildId)

// Cancel a giveaway
await GiveawayManager.cancel(giveawayId)
```

## Configuration

Configure in `config/plugins/robojs/giveaways.mjs`:

```javascript
export default {
  embedColor: '#5865F2',
  buttonLabel: 'Enter Giveaway',
  winnerMessage: 'Congratulations {winners}! You won **{prize}**!'
}
```
