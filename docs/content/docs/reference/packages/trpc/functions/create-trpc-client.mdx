# Function: createTRPCClient()

```ts
function createTRPCClient<AppRouter>(opts): CreateTRPCClient<AppRouter>
```

Creates a tRPC client for making type-safe API calls to a tRPC server from Robo.js.

## Type Parameters

| Type Parameter | Extends | Description |
| -------------- | ------- | ----------- |
| `AppRouter` | `Router<object, object>` | The type of your tRPC router |

## Parameters

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `opts` | `CreateTRPCClientOptions<AppRouter>` | Configuration options for the tRPC client |

## Returns

`CreateTRPCClient<AppRouter>` - A type-safe tRPC client for making API calls

## Example

```ts
import { createTRPCClient, httpBatchLink } from '@robojs/trpc'
import type { AppRouter } from './server/routers'

// Create a tRPC client
const client = createTRPCClient<AppRouter>({
  links: [
    httpBatchLink({
      url: 'http://localhost:3000/api/trpc',
    }),
  ],
})

// Use the client to make type-safe API calls
async function fetchUsers() {
  try {
    // This call is fully type-safe
    const users = await client.users.list.query()
    console.log('Users:', users)
    
    // Create a new user
    const newUser = await client.users.create.mutate({
      name: 'John Doe',
      email: 'john@example.com'
    })
    console.log('Created user:', newUser)
  } catch (error) {
    console.error('Error fetching users:', error)
  }
}
```

## With Robo.js Server

For Robo.js applications, you can connect to the built-in tRPC endpoint:

```ts
import { createTRPCClient, httpBatchLink } from '@robojs/trpc'
import type { AppRouter } from './api/trpc/[trpc]'

const client = createTRPCClient<AppRouter>({
  links: [
    httpBatchLink({
      url: '/api/trpc',
    }),
  ],
})

// Now you can use the client
const result = await client.someEndpoint.query()
```

## Notes

- This function is a wrapper around tRPC's createClient that works well with Robo.js
- The client provides full type safety for your API calls
- Use with `httpBatchLink` for optimal performance (batches multiple requests)
- For React applications, consider using `createTRPCReact` instead
