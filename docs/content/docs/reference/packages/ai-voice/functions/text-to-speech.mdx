# Function: textToSpeech()

```ts
function textToSpeech(text, filePath): Promise<string>
```

Converts text to speech and saves the resulting audio to a file.

## Parameters

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `text` | `string` | The text to convert to speech |
| `filePath` | `string` | The path where the audio file will be saved |

## Returns

`Promise<string>` - Resolves to the path of the saved audio file

## Example

```ts
import { textToSpeech } from '@robojs/ai-voice'

async function createWelcomeMessage() {
  try {
    const audioPath = await textToSpeech(
      'Welcome to my Discord server! I hope you enjoy your stay.',
      './welcome-message.mp3'
    )
    
    console.log(`Audio file created at: ${audioPath}`)
    
    // You can now use this audio file, for example, sending it in Discord
    // or playing it through a voice channel
  } catch (error) {
    console.error('Failed to generate speech:', error)
  }
}
```

## Notes

- The function returns a Promise that resolves when the audio file has been created
- The input text should be a reasonable length for conversion to speech
- The file path should include the appropriate extension (typically .mp3)
- Make sure the directory where you're saving the file exists and is writable
