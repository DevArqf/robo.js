## Accessors

### params

#### Get Signature

```ts
get params(): Record<string, string>
```

Provides access to route parameters (e.g., for `/users/:id`, `params.id` would contain the extracted value).

##### Returns

`Record<string, string>` - Object containing route parameters

### from()

```ts

```

Creates a RoboRequest from a Node.js IncomingMessage.

#### Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |

#### Returns

`Promise<RoboRequest>` - A Promise resolving to a new RoboRequest instance

## Example

```ts
// In an API route handler
export default async function(request, reply) {
  // Get route parameters
  const userId = request.params.id
  
  // Get query parameters
  const { sort, filter } = request.query
  
  // Parse JSON body
  const body = await request.json()
  
  // Send a response
  return reply.json({ 
    userId, 
    sort, 
    filter,
    receivedData: body
  })
}
```
