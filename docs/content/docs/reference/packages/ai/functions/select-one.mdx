# Function: selectOne()

```ts
function selectOne(
   selection, 
   choices, 
options?): Promise<string | null>
```

Present users with a selection menu and let them choose one option.

## Parameters

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `selection` | `string` | The prompt text to show the user |
| `choices` | `string[]` | Array of options to present to the user |
| `options` | `SelectOneOptions` | Optional configuration for the selection menu |

## Returns

`Promise<string | null>` - Resolves to the selected choice or null if cancelled

## Example

```ts
import { selectOne } from '@robojs/ai'

async function askUserPreference() {
  const choice = await selectOne(
    'What is your favorite color?',
    ['Red', 'Green', 'Blue', 'Yellow']
  )
  
  if (choice) {
    console.log(`You selected: ${choice}`)
  } else {
    console.log('You cancelled the selection')
  }
}
```

## Notes

- The function returns a Promise that resolves when the user makes a selection
- If the user cancels or doesn't respond, the promise resolves to `null`
- The first parameter (`selection`) is displayed as the prompt text
- The second parameter (`choices`) must be an array of strings to show as options
