---
title: "CommandIntegrationType"
description: "Define how a command is installed in Discord"
---

Specifies how a command can be installed in Discord. This controls whether a command is installed at the guild level, user level, or using a Discord application integration type.

```typescript
import { createCommandConfig } from 'robo.js'

// Create a command that's only available when installed in a guild
const guildCommand = createCommandConfig({
  integrationTypes: ['GuildInstall'],
  description: 'This command only works in servers'
})

// Create a command that's available for user installations
const userCommand = createCommandConfig({
  integrationTypes: ['UserInstall'],
  description: 'This command works in user contexts'
})

// Create a command that works in both contexts
const universalCommand = createCommandConfig({
  integrationTypes: ['GuildInstall', 'UserInstall'],
  description: 'This command works everywhere'
})
```

## Type Declaration

```typescript
type CommandIntegrationType: "GuildInstall" | "UserInstall" | ApplicationIntegrationType;
```

<TypeTable
  type={{
    "GuildInstall": {
      description: 'Command is installed at the guild (server) level',
      type: 'string literal'
    },
    "UserInstall": {
      description: 'Command is installed at the user level (for user-specific functionality)',
      type: 'string literal'
    },
    "ApplicationIntegrationType": {
      description: 'Other application integration types from Discord.js',
      type: 'type'
    }
  }}
/>

<Callout type="info" title="Default Behavior">
  When no integration types are specified, commands default to guild installation.
</Callout>

<Callout type="info" title="Usage Note">
  User-installed commands are useful for actions that don't need a server context.
</Callout>
