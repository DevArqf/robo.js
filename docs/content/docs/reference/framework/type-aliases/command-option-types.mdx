Defines the supported types for Discord command options, mapping the option type name to its corresponding JavaScript/TypeScript type.

```typescript
import { createCommandConfig } from 'robo.js'

// Create a command with different option types
const myCommand = createCommandConfig({
  description: 'A command with various option types',
  options: [
    {
      name: 'text',
      description: 'A text input',
      type: 'string',
      required: true
    },
    {
      name: 'count',
      description: 'A number input',
      type: 'integer',
      min: 1,
      max: 100
    },
    {
      name: 'enabled',
      description: 'Toggle feature',
      type: 'boolean'
    }
  ]
})
```


## Usage in Commands

When implementing the command handler, the option values will be automatically parsed and typed according to this mapping:

```typescript
export default function(interaction, options) {
  // options are typed according to CommandOptionTypes
  const text = options.text           // string
  const count = options.count         // number
  const enabled = options.enabled     // boolean
  const targetUser = options.target_user     // User object
  const targetChannel = options.target_channel  // GuildBasedChannel object
  
  // Use the typed values
  interaction.reply(`You provided: ${text}, ${count}, ${enabled}`)
}
```

<Callout type="info" title="Type Safety">
  The options object in command handlers is automatically typed according to the CommandOptionTypes mappings, providing type safety in your code.
</Callout>
