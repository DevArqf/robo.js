---
title: "CommandContext"
description: "Define where a command can be used in Discord"
---

Specifies the contexts where a command can be used in Discord. This controls the visibility and availability of commands in different parts of Discord.

```typescript
import { createCommandConfig } from 'robo.js'

// Create a command that's only available in guilds (servers)
const guildOnlyCommand = createCommandConfig({
  contexts: ['Guild'],
  description: 'This command only works in servers'
})

// Create a command that works everywhere
const universalCommand = createCommandConfig({
  contexts: ['Guild', 'BotDM', 'PrivateChannel'],
  description: 'This command works everywhere'
})
```

## Type Declaration

```typescript
type CommandContext: "BotDM" | "Guild" | "PrivateChannel" | InteractionContextType;
```

<Callout type="info" title="Default Behavior">
  When no contexts are specified, commands default to all available contexts.
</Callout>

<Callout type="info" title="Compatibility Note">
  The `contexts` property in command configuration replaces the deprecated `dmPermission` property.
</Callout>
