---
title: "Robo"
description: "Main entry point for Robo.js"
---

The `Robo` variable is the main entry point for your bot. It provides a simple API for starting, stopping, and restarting your Robo.js application programmatically.

```typescript
import { Robo } from 'robo.js'

Robo.start()
```

<Callout type="info" title="CLI Alternative">
  You do not normally need to use this API directly, as the CLI will handle starting and stopping for you.
</Callout>

## Type Declaration

```typescript
const Robo: object;
```

## Example

```typescript
import { Robo } from 'robo.js'

// Start your Robo
await Robo.start()

// Later, restart your Robo programmatically
await Robo.restart()

// Stop your Robo with a custom exit code
await Robo.stop(1)
```
