---
title: "Flashcore"
description: "Key-value database for long-term storage in Robo.js"
---

The `Flashcore` variable provides a built-in key-value database for long-term storage in your Robo.js applications. It allows you to store, retrieve, and watch data that persists across sessions and restarts.

```typescript
import { Flashcore } from 'robo.js'

await Flashcore.set('key', 'value')
const value = await Flashcore.get('key')
await Flashcore.delete('key')
```

<Callout type="info" title="Asynchronous API">
  All Flashcore APIs are asynchronous. Use this to store and retrieve data across sessions. Defaults to file-based storage, but can be configured to use other engines using Keyv adapters.
</Callout>

## Example

```typescript
import { Flashcore } from 'robo.js'

// Initialize Flashcore with custom options
await Flashcore.$init({
  adapter: new CustomStorageAdapter()
})

// Basic operations
await Flashcore.set('user:1234', { name: 'RoboUser', level: 5 })
const user = await Flashcore.get('user:1234')
console.log(user.name) // 'RoboUser'

// Check if a key exists
const exists = await Flashcore.has('user:1234') // true

// Watch for changes
Flashcore.on('user:1234', (newValue, oldValue) => {
  console.log(`User changed from ${oldValue.level} to ${newValue.level}`)
})

// Update the value
await Flashcore.set('user:1234', { name: 'RoboUser', level: 6 })
// Console: "User changed from 5 to 6"

// Stop watching
Flashcore.off('user:1234')

// Delete the key
await Flashcore.delete('user:1234')

// Clear all data
await Flashcore.clear()
```
