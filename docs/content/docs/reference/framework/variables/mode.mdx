---
title: "Mode"
description: "Define profiles for your Robo.js session"
---

The `Mode` variable allows you to define "profiles" for your Robo.js session. Each mode can have its own configuration, environment variables, and code behavior.

```typescript
import { Mode } from 'robo.js'

// Get the current mode
const mode = Mode.get()

// Check if the current mode is "dev"
if (Mode.is('dev')) {
 // Do something
}

// Colorize text based on the current mode
console.log(Mode.color('Hello, world!'))
```

<Callout type="info" title="Multiple Modes">
  Everything is granular. You can even run multiple modes at the same time!
</Callout>

## Type Declaration

```typescript
const Mode: Readonly<object>;
```

## Methods


## Example

```typescript
import { Mode } from 'robo.js'

// Get the current mode
const currentMode = Mode.get()
console.log(`Running in ${currentMode} mode`)

// Check if we're in development mode
if (Mode.is('development')) {
  console.log('Development features enabled')
}

// Check if we're in production mode
if (Mode.is('production')) {
  console.log('Production optimizations enabled')
}

// Use different colors based on mode
const logHeader = Mode.color('=== Robo Starting ===')
console.log(logHeader) // Will be colored based on current mode
```
