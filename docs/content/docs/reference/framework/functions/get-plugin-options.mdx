Gets the config options for a specific plugin package. This function allows plugin authors to access their plugin's configuration data.

## `getPluginOptions()`

```typescript
function getPluginOptions(packageName: string): unknown | null
```

Gets the config options for a specific plugin package.

  <Step>

        }
      }}
    />
  </Step>
  <Step>
    **Returns**
    <ReturnType
      type={{
        type: 'unknown | null',
