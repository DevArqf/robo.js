---
title: "State"
description: "In-memory state management for Robo.js"
---

The `State` class provides an in-memory key-value store for your Robo, acting as its personal memory bank. It's useful for managing temporary data that needs to be accessed across different parts of your application or between command executions.

```typescript
// Set a value in the global state
State.set('currentUser', 'RoboFan123');

// Get a value from the global state
const user = State.get('currentUser');
console.log(user); // Output: RoboFan123
```

<Callout type="info" title="Ephemeral Storage">
  State data is stored in-memory. This means it will be lost if the Robo process stops completely. However, data persists through automated restarts.
</Callout>


Creates a new, isolated `State` instance with a specific namespace (prefix). This is less common than using the static `State.fork()` method for creating namespaced states.

## Instance Methods

These methods are available on an instance of `State` (e.g., one created via `new State(...)` or `State.fork(...)`).

### `fork()`
```typescript
fork(prefix: string, options?: StateOptions): State
```

Creates a new state fork (child namespace) from an existing state instance. This allows for hierarchical state management.

          required: true

        options: {

## Static Methods

These methods are called directly on the `State` class (e.g., `State.get(...)`).

### `static fork()`
```typescript
static fork(prefix: string, options?: StateOptions): State
```

Creates a new, top-level state fork (namespaced state). This is the recommended way to create isolated states for different features or modules to prevent key collisions in the global state.

<Steps>
  <Step>
    **Parameters**
    <TypeTable
      type={{
        prefix: {
          description: "The prefix for the new fork (e.g. 'polls', 'analytics').",
          type: 'string',
          required: true
        },
        options: {
          description: 'Options for the new fork. By default, forks persist all their state if the global persistence is enabled.',
          type: 'StateOptions',
          required: false
        }
      }}
    />
  </Step>
  <Step>
    **Returns**
    <ReturnType
      type={{
        type: 'State',
        description: (
        <>
        A new State instance representing the fork. Its methods (getState, setState) will operate within this namespace.<br/><br/>
        Example:<br/><br/>
        <code>const pollState = State.fork('polls');<br/>pollState.setState('current', 'poll123')</code>
        </>
        )
      }}
    />
  </Step>
  ---
</Steps>
