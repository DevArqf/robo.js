---
title: "Env"
description: "Manage environment variables in Robo.js"
---

The `Env` class helps manage environment variables in your Robo.js project. It allows you to load variables from a `.env` file and access them in a type-safe manner, with support for schemas and default values.

```typescript
import { Env } from 'robo.js';

// Load environment variables (e.g., for development mode)
Env.loadSync({ mode: 'dev' });

// Access loaded variables
console.log(Env.data().NODE_ENV); // Output: 'development' (if set)
```

### `static loadSync()`
```typescript
static loadSync(options?: LoadOptions): Record<string, string>
```

Synchronously loads environment variables from a `.env` file and applies them to `process.env`.

<Callout type="warn" title="Blocking Operation">
  This method is synchronous and will block the main thread. Prefer the asynchronous `load()` method for non-blocking operations, especially in production or performance-sensitive contexts.
</Callout>
